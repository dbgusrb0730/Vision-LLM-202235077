# Vision-LLM-202235077

**202235077 유현규**

컴퓨터 비전과 로컬 LLM을 학습하고, Jetson Orin Nano를 활용한 시청각 멀티모달 시스템을 구현하는 수업 실습 저장소입니다. 강의 노트북, 일일 과제, 프로젝트 코드를 정리했습니다.

## 과정 개요

- 개발 환경 설정 및 Linux·Python 기초
- OpenCV 기반 컴퓨터 비전과 딥러닝·GPU 실습
- YOLO 객체 탐지와 Gemma 로컬 LLM 활용
- 영상·음성을 결합한 멀티모달 시스템 구현
